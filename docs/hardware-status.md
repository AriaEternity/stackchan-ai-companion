# 硬件状态与已知限制

本开源快照包含已开发的软件能力，以及尚未完成实机验收的定制固件。2026-08 的维护记录显示，项目随后主动暂停，原设备恢复原厂 v1.4.4，原自托管服务停止。

## 已有软件实现

- 登录、消息持久化、记忆确认与增量同步。
- 有界协议、心跳、掉线恢复、触摸会话与文字显示。
- 命名动作调度、服务器锁定策略和设备本地校准配置。
- 对上述纯逻辑的 Python/C++ 离线测试。

## 尚未完成

- 部分网页动作曾收到 `completed`，但现场观察到位移不明显，动作效果验收未通过。
- 动作方向、幅度、实际到位与保持时间需要重新建立设备基线。
- 下一阶段的“根据文字语义产生更明显的水平动作”停留在计划阶段。
- 相机、麦克风、语音、音频输出未接入 Companion。
- 公开源码基于上游 1.4.3，不等同于原厂 1.4.4 固件。

## 使用边界

优先使用无设备演示和宿主测试。仓库不分发整机镜像、NVS、分区备份、可刷写固件或生产资料，也不提供一键刷写。需要实机开发时，应先阅读[固件构建说明](firmware.md)，自行验证供电、机械基线与恢复方法。

固件默认校准门和服务器动作锁是独立的：解除一层不代表另一层通过，更不代表设备经过校准。宿主测试里的假执行器范围不能直接当作真实设备限位。

项目没有启用 Flash Encryption 或 Secure Boot。物理配网凭据保存在 NVS，不能把这个实验版本描述成具备加密存储或硬件安全保证。
